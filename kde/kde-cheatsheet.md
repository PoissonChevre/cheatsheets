# KDE Plasma 6 - Keyboard Shortcuts

Default shortcuts on Plasma 6 (Fedora KDE). `Meta` = Super / Windows key.
Lines marked (custom) are personal shortcuts, not Plasma defaults.

Change them in: System Settings > Keyboard > Shortcuts.
Config file: `~/.config/kglobalshortcutsrc` (can be tracked with chezmoi).

---

## Launch and session

| Shortcut | Action |
|---|---|
| `Meta` | Open application launcher |
| `Alt+Space` or `Alt+F2` | KRunner (run command, search, calculator) |
| `Ctrl+Alt+T` | Open Konsole |
| `Meta+E` | Open Dolphin |
| `Meta+K` | Open calculator (custom) |
| `Meta+V` | Clipboard history |
| `Ctrl+Esc` | System Monitor |
| `Meta+L` | Lock screen |
| `Ctrl+Alt+Del` | Logout / shutdown screen |
| `Meta+P` | Display configuration (external screen) |

---

## Windows

| Shortcut | Action |
|---|---|
| `Alt+Tab` / `Alt+Shift+Tab` | Switch windows |
| `Alt+F4` | Close window |
| `Alt+F3` | Window menu |
| `Meta+PgUp` | Maximize |
| `Meta+PgDown` | Minimize |
| `Meta+Left` / `Meta+Right` | Tile window to left / right half |
| `Meta+Up` / `Meta+Down` | Tile window to top / bottom half |
| `Meta+T` | Custom tiling editor |
| `Meta+Shift+Left` / `Right` | Move window to other screen |
| `Meta+Left drag` | Move window |
| `Meta+Right drag` | Resize window |
| `Meta+Shift+-` / `Meta+Shift++` | Decrease / increase window opacity (custom) |
| `Ctrl+Alt+Esc` | Kill a frozen window (click on it) |

## Desktops and overview

| Shortcut | Action |
|---|---|
| `Meta+W` | Overview |
| `Meta+G` | Grid view (all virtual desktops) |
| `Meta+D` | Show desktop |
| `Ctrl+F1` to `Ctrl+F4` | Go to virtual desktop 1 to 4 |
| `Ctrl+Meta+Left` / `Right` | Previous / next virtual desktop |
| `Meta+1` to `Meta+9` | Open or focus app pinned in task manager |

## Konsole

| Shortcut | Action |
|---|---|

| `Ctrl+Shift+W` | Close tab |
| `Shift+Left` / `Shift+Right` | Previous / next tab |
| `Ctrl+Shift+Left` / `Right` | Move tab |
| `Ctrl+(` | Split view left / right |
| `Ctrl+)` | Split view top / bottom |
| `Ctrl+Shift+C` / `Ctrl+Shift+V` | Copy / paste |
| `Ctrl+Shift+F` | Search in output |
| `Ctrl++` / `Ctrl+-` | Bigger / smaller font |
| `Ctrl+Shift+N` | New window |
| `Ctrl+Shift+M` | Show / hide menu bar |

## Dolphin

| Shortcut | Action |
|---|---|
| `F4` | Embedded terminal panel |
| `F3` | Split view |
| `F9` | Show / hide Places panel |
| `Ctrl+L` | Edit path |
| `Alt+.` or `Ctrl+H` | Show / hide hidden files |
| `Ctrl+T` | New tab |
| `Ctrl+F` | Search |
| `F2` | Rename |
| `F10` | New folder |
| `Alt+Up` | Parent folder |
| `Alt+Left` / `Alt+Right` | Back / forward |
| `Shift+Del` | Delete permanently **!** no trash |

---

## Tips

- Shortcuts can change between Plasma versions: check System Settings if one does not work.
- Back up `~/.config/kglobalshortcutsrc` before a reinstall to keep custom shortcuts.
